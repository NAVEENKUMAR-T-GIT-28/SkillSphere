# Purpose

This document defines the complete data contract for the Student Notifications page.

It includes

- Notification Feed
- Search
- Mark Read
- Mark All Read
- Notification Types
- EventBus Integration
- Pagination

The Notification Domain is responsible for delivering system events generated by all SkillSphere domains.

PERFORMANCE GUIDELINES
================================================================================

✔ Use pagination.

✔ Sort newest first.

✔ Index by user_id and created_at.

✔ Unread count should be cached.

================================================================================
CQRS RULES
================================================================================

✔ Notifications are append-only.

✔ Domains never modify notifications directly.

✔ Notifications are created from domain events.

✔ Read status belongs only to Notification Domain.

================================================================================
DEVELOPMENT RULES
================================================================================

✔ Every domain publishes events.

✔ Notification service subscribes to events.

✔ Student pages never create notifications directly.

✔ Notifications should remain immutable except read status.
